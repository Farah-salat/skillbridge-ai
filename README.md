## 📋 Overview
**SkillBridge AI** converts undocumented professional experience into verified proof of competency for skilled refugees in Kenya.

## ✨ Key Features
* **3-Step Competency Verification Flow:** Experience intake, scenario-based assessment, and a verifiable digital competency passport.
* **Employer Verification Portal:** Instant candidate ID and skill verification for hiring partners.
* **Sample Profiles:** Pre-loaded demo profiles for testing.

## 🛠️ Technology Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Deployment:** Git, GitHub, and Netlify
